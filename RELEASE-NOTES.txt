DJW Player 0.3.5 test — Android 8+ / arm64

Install over the existing DJW Player app to keep your settings and library.

Changes:
- AVI/legacy video compatibility playback and decoder fallback.
- Live move progress in the library and Soulseek.
- Separate copying and verification stages.
- Move complete only after verified relocation and original-file cleanup.
- Clear message if a verified copy is saved but the original must be kept.

141 automated tests passed. Actual AVI files, SD-card providers and real Samba
playback still need device testing. This is an early personal test build.

This release does not yet contain the GitHub update checker. That will be wired
to this repository in a subsequent Android build.
